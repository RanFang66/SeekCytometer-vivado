# 信号基线自动识别与基线校正设计方案

> 适用范围：`signal_analyzer` 自定义 IP（`ip_repo/signal_analyzer_1_0`）
> 相关模块：`pulse_analyzer.v`、`ad_data_filter.v`、`signal_analyzer_v1_0_S00_AXI.v`
> 状态：设计草案（未实现）

---

## 1. 背景与目标

### 1.1 现状

PL 端 `signal_analyzer` IP 负责 8 通道 ADC 信号的实时分析，数据链路为：

```
ad_data_filter(4点均值) → pulse_analyzer×8(脉冲检测 + 峰/宽/面积) → event_aggregator → BRAM → PS → 上位机
```

当前 `pulse_analyzer.v` 的脉冲特征计算全部基于**绝对 ADC 码值**：

| 特征 | 当前实现 | 位置 |
|---|---|---|
| 检测阈值 | `sample_in > threshold_value`（绝对比较） | `pulse_analyzer.v:72,101` |
| 峰值 | `peak = max(sample_in)` | `pulse_analyzer.v:83,94-97` |
| 面积 | `area = Σ sample_in` | `pulse_analyzer.v:85,98` |

其中 `threshold_value` 由 PS 经 AXI 寄存器 `slv_reg8~15` 下发（每通道一个，18 bit）。

### 1.2 问题

1. **基线漂移直接污染峰/面积**：PMT 暗电流、电子学温漂、激光/荧光本底、光电转换偏置等使 ADC 基线（直流偏置）在实验过程中缓慢漂移。当前 peak/area 不扣除基线，漂移量被直接计入结果，导致：
   - 峰值测量系统性偏高/偏低；
   - 面积测量随漂移累积误差。
2. **绝对阈值在漂移下失效**：
   - 漂移上移越过阈值 → **误触发**（把本底当脉冲）；
   - 漂移下移 → 脉冲幅度相对阈值变小 → **漏触发**。

### 1.3 目标

- 在 PL 内自动识别并实时跟踪每通道信号基线；
- 峰/面积等特征减去基线，得到「相对基线」的准确结果；
- 检测阈值由绝对改为相对（`sample - baseline > threshold`），使触发不受漂移影响；
- 纯硬件实现，不影响 1 MHz × 8 通道实时性；
- **不改变 `peak_time`**（分选驱动延时依赖峰值时刻，减法不移动峰值位置，时序不受影响）。

### 1.4 非目标

- 不做多通道之间的串扰校正；
- 不做非线性（多项式/样条）基线拟合——漂移是慢的，线性跟踪足够；
- 不改动 `event_aggregator` 的事件打包格式。

---

## 2. 方案概述

每通道增加一个 `baseline_estimator` 模块，与 `pulse_analyzer` **并行**，输出该通道基线 `baseline_out` 与基线校正后的 `sample_baselined`。核心设计决策：

| 决策点 | 选择 | 理由 |
|---|---|---|
| 估计器 | 泄漏积分器（EMA / IIR） | 每通道仅 1 减法 + 1 移位 + 1 累加寄存器；跟踪平滑；资源远小于滑动窗口 |
| 更新门控主判据 | `!pulse_active`（来自 `pulse_analyzer` FSM） | FSM 自带上升/下降沿去抖，比「差分阈值」判别「是否在脉冲中」更可靠 |
| 更新门控辅助判据 | 下降沿后守门 + 斜率二级门控（可选） | 守门压 4 点滤波后振铃；斜率门控拦截亚阈值脉冲边沿 |
| 检测阈值 | 相对化 `(sample-baseline) > threshold` | 漂移不再影响触发，且修正了绝对阈值的隐性 bug |
| 引导问题 | 两阶段状态机（ACQUIRE → TRACK） | 打破「检测需要基线 / 基线需要检测」的闭环 |
| 数据流 | 无环：pulse_analyzer 用「上一拍 baseline」，baseline 用「上一拍 pulse_active」 | 避免组合逻辑环，一拍延迟对慢变量无影响 |

## 3. 详细设计

### 3.1 数据流与无环设计

```
ad_data_array[i] (ad_data_filter 滤波后，18 bit 有符号)
   │
   ├──► pulse_analyzer（检测 + 峰/宽/面积）
   │        检测:  (sample - baseline_out) > threshold        [baseline_valid=0 时退回绝对阈值，见 3.4]
   │        peak:  max(sample - baseline_out)
   │        area:  Σ(sample - baseline_out) = Σsample - baseline_out * width
   │
   └──► baseline_estimator（每通道一个）
           update_en = !pulse_active & settle_done & (|diff| < slope_th)
           baseline  <= baseline + ((sample - baseline) >>> K)
```

**无环说明**：`pulse_active` 与 `baseline_out` 都是寄存器输出，存在一拍延迟。交叉使用时形成的是「上一拍状态 → 本拍更新」的合法时序，无组合逻辑环。基线是慢变量，一拍延迟无影响。

**面积公式等价性**：由于基线在脉冲期间**冻结**（`!pulse_active` 门控），脉冲内 `baseline_out` 恒定，因此逐样本减与度量级减严格等价：

```
area_corrected = Σ(sample - baseline) = Σsample - baseline × width
peak_corrected = max(sample - baseline) = max(sample) - baseline   （baseline 恒定）
```

实现上可选「逐样本减」或「`pulse_done` 时度量级减」，见 6.1 分阶段落地。

### 3.2 两阶段状态机

**问题**：相对检测 `(sample-baseline) > threshold` 需要 baseline，而 baseline 更新门控 `!pulse_active` 又依赖检测结果。若一开始就用相对检测，baseline 初始化为 0 时，真实基线（如 ADC 码 10000）会被误判成「巨大脉冲」，`pulse_active` 恒 1，跟踪器死锁。

**解法**：显式两阶段，用 `baseline_valid` 打破闭环。

```
        ┌────────────────────────────────────────────────────────┐
        │  ACQUIRE（开环快速收敛，baseline_valid = 0）             │
        │  · update_en 恒 1（不用 pulse_active，或用斜率门控）      │
        │  · 快速 EMA：baseline += (sample - baseline) >>> 4      │
        │  · 计数到 N 拍（默认 1024）→ 置 baseline_valid=1，进 TRACK │
        └────────────────────────────────────────────────────────┘
                              │ baseline_valid = 1
                              ▼
        ┌────────────────────────────────────────────────────────┐
        │  TRACK（闭环慢速跟踪，baseline_valid = 1）               │
        │  · 检测切换为相对阈值                                    │
        │  · update_en = !pulse_active & settle_done & 斜率门控    │
        │  · 慢速 EMA：baseline += (sample - baseline) >>> K      │
        │  · acquire_force 或看门狗超时 → 退回 ACQUIRE             │
        └────────────────────────────────────────────────────────┘
```

**开环快速收敛为何安全**：

1. **收敛方向对**：正脉冲稀疏（占空比 ~1%），快速 EMA 收敛到 `mean ≈ baseline + duty·pulse_mean`，略高于真实基线。用这个「略高」的基线做相对检测时，真实基线样本的 `sample-baseline` 略为负，`< threshold`，正确判为「非脉冲」——偏差方向安全，不会误触发。
2. **闭环阶段修正**：进入 TRACK 后，门控跟踪把这一小偏差逐步修正掉。
3. **时序上本就留有窗口**：采集启动到真正有样本流过之间天然有间隔（引导式实验流程把液路启动放在最后），毫秒级的开环窗口足够。

**收敛判据**：采用固定样本数 `N`（确定性、简单），可选升级为「连续 M 拍更新步长 < ε」的收敛判据。初值直接取首个样本可进一步加速收敛（见 3.5）。

### 3.3 运行期自愈

启动闭环解决了，运行中还有同类风险：**PS 改写增益 / 门控参数、或基线突然大跳**，会使相对检测误锁，`pulse_active` 长高，跟踪再次冻结。因此加：

1. **看门狗**：若 `pulse_active` 持续高电平超过 `MAX_PULSE_WID`（默认 255 拍，须远大于任何真实脉冲宽度），判为「检测卡死」，强制退回 ACQUIRE 重新收敛。
2. **`acquire_force`**：PS 在改写检测器增益/门控参数时拉一下，主动触发重收敛。

两条保证系统在任意时刻可自愈，而非只在启动时安全。

### 3.4 相对阈值的接入

`pulse_analyzer` 的阈值比较改为相对，但在 `baseline_valid=0` 时退回绝对阈值（复用现有行为，避免引入启动回归）：

```verilog
wire signed [17:0] detect_ref = baseline_valid
                               ? (baseline_out + threshold_value[i])
                               : threshold_value[i];
```

即：ACQUIRE 阶段检测沿用现有绝对阈值，TRACK 阶段切为相对阈值。

### 3.5 定点表示

- 采样值：18 bit 有符号（`C_AD_DATA_DEPTH = 18`）。
- 基线内部存储：`18 整数 + 6 小数`（`C_FRAC_BITS = 6`）定点，避免 EMA 每次移位截断造成的粘滞量化误差。
- 输出 `baseline_out`：取整回 18 bit 供减法与检测使用。
- 校正后 `sample_baselined`：18 bit 有符号（减法可能变负，符合预期）。

### 3.6 模块接口

```verilog
module baseline_estimator #(
    parameter integer C_AD_DATA_DEPTH = 18,
    parameter integer C_FRAC_BITS     = 6,     // baseline 小数位
    parameter integer C_ACQUIRE_LEN   = 1024,  // 开环收敛样本数 N
    parameter integer C_GUARD_LEN     = 8,     // 下降沿后守门拍数
    parameter integer C_MAX_PULSE_WID = 255    // 看门狗阈值
)(
    input  wire clk,
    input  wire rst_n,
    input  wire sample_valid,                        // = ad_data_updated（滤波数据更新沿）
    input  wire signed [C_AD_DATA_DEPTH-1:0] sample_in,   // 滤波后采样值
    input  wire pulse_active,                        // 来自 pulse_analyzer（寄存，晚 1 拍）
    input  wire acquire_force,                       // PS：增益跳变/复位时触发重收敛
    input  wire [4:0]  alpha_shift,                  // 慢跟踪 K（α = 2^-K），默认 10
    input  wire signed [7:0] slope_th,               // 斜率二级门控阈值，<=0 表示禁用
    output wire baseline_valid,                      // 1 = 基线可信，检测可切相对阈值
    output wire signed [C_AD_DATA_DEPTH-1:0] baseline_out,       // 取整后基线
    output wire signed [C_AD_DATA_DEPTH-1:0] sample_baselined    // sample - baseline，喂 pulse_analyzer
);
```

### 3.7 关键更新逻辑（伪代码）

```verilog
// 门控：主门 = FSM 不在脉冲中；守门 = 下降沿后若干拍内不更新；二级 = 斜率门控
wire slope_ok = (slope_th <= 0) || (|sample_in - sample_prev| < slope_th);
wire in_baseline = !pulse_active && (guard_cnt == 0) && slope_ok;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        state <= S_ACQUIRE;
        baseline <= {1'b0, sample_in, {C_FRAC_BITS{1'b0}}};  // 以首个样本作初值
        baseline_valid <= 1'b0;
    end else if (sample_valid) begin
        // 看门狗计数
        if (pulse_active) wid_cnt <= (wid_cnt == C_MAX_PULSE_WID) ? wid_cnt : wid_cnt + 1;
        else              wid_cnt <= 0;

        case (state)
        S_ACQUIRE: begin
            baseline <= baseline + ((sample_in - baseline) >>> 4);   // 快速，update_en 恒 1
            if (cnt == C_ACQUIRE_LEN) begin
                state <= S_TRACK; baseline_valid <= 1'b1;
            end else cnt <= cnt + 1;
        end
        S_TRACK: begin
            if (in_baseline)
                baseline <= baseline + ((sample_in - baseline) >>> alpha_shift);
            if (acquire_force || (wid_cnt == C_MAX_PULSE_WID)) begin
                state <= S_ACQUIRE; baseline_valid <= 1'b0; cnt <= 0;
            end
        end
        endcase
    end
end
```

**注意**：`baseline`、`baseline_valid` 是**跨事件的慢状态**，绝不能随 `event_done`（事件边界）清零——否则漂移追踪即断。现有 `event_done` 会清「无脉冲通道」的 peak/area（code_review 7.2 的修复），基线不在此列，需在实现中明确区分。

## 4. 参数表

| 参数 | 符号 | 默认值 | 说明 |
|---|---|---|---|
| 快收敛移位 | K_fast | 4 | ACQUIRE 阶段 α = 2^-4 |
| 慢跟踪移位 | K（`alpha_shift`） | 10 | TRACK 阶段 α = 2^-10，τ ≈ 1024 拍基线时间 |
| 开环样本数 | N（`C_ACQUIRE_LEN`） | 1024 | 约 1 ms @1 MHz |
| 守门拍数 | `C_GUARD_LEN` | 8 | 下降沿去抖后再等 8 拍，压 4 点滤波后振铃 |
| 斜率门控阈值 | `slope_th` | 0（禁用） | 亚阈值边沿拦截，需实验标定后启用 |
| 看门狗阈值 | `C_MAX_PULSE_WID` | 255 | 须 > 最大真实脉宽 |
| 小数位 | `C_FRAC_BITS` | 6 | 基线定点精度 |

**K 取值说明**：漂移是秒级过程，而基线仅在非脉冲间隙被更新（更新有效速率 = 采样率 × 非脉冲占空比）。K=10 在 1 MHz 下对应约 1 ms 的基线累计时间常数，对秒级漂移足够灵敏，又足够慢不会被单次噪声带动。若事件率极高导致非脉冲间隙极短，可适当增大 K（如 12）。

## 6. 实现步骤

### 6.1 分阶段落地

**阶段 0：参数定标与定点分析**
- **ADC 定标（已确认，2026-10-14）**：AD7606C-18，18 bit、1 MHz 采样、±5V 双极性（二进制补码）。真实基线量级 **数千 ~ 10000**（ADC 码，正向直流偏置）；漂移速率 **数秒约 1 个 AD 码**。
- **据此参数复核**：基线 ~10000 在 18 bit 有符号范围内远小于满幅，Q(18.6) 定点（`baseline ≈ 10000×64 = 640000`，24 bit 有符号上限 8.4M）余量充足；漂移 ~1 码/数秒，`K=10`（τ≈1024 拍≈1 ms）对其足够灵敏且足够慢不被单次噪声带动，默认值**无需调整**。
- ~~确认各通道脉冲极性~~ —— **已确认：全部正脉冲，无负向通道，无需极性参数**（见第 10 节决议 1）。

**阶段 1：`baseline_estimator.v` + 度量级减法（不动检测）**
- 先实现模块，只做 ACQUIRE/TRACK + EMA，输出 `baseline_out`。
- `pulse_analyzer` 检测保持绝对阈值不变，仅在 `pulse_done` 时用 `peak_raw - baseline`、`area_raw - baseline*width` 做度量级校正。
- **验证目标**：确认基线确实在跟踪漂移（通过回读或 ILA），峰/面积校正方向正确。改动面最小，不引入触发回归。

**阶段 2：相对阈值 + 门控接线**
- `pulse_analyzer` 阈值改相对（`detect_ref`），`baseline_valid=0` 退回绝对阈值。
- `baseline_estimator` 接入 `pulse_active` 门控 + 守门 + 斜率二级门控。
- 验证：漂移场景下触发不再误触/漏触。

**阶段 3：自愈与监控**
- 加看门狗、`acquire_force`、回读寄存器。
- 验证：增益跳变后自动重收敛。

**阶段 4：PS 端驱动与上位机**
- `signal_analyzer.c/.h` 增加基线寄存器读写函数。
- 上位机下发/回读参数与基线（诊断/校准用途）。

**阶段 5：综合、时序收敛、上板 ILA 验证**
- 综合检查资源增量（8 通道 EMA 极小）与时序（路径在 `sample_valid` 域，非关键路径）。
- ILA 抓取验证（见 8.2）。

## 7. 风险点

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| 1 | 平顶/宽脉冲平台区被误判为基线 | 基线被脉冲拉高 | 主门用 FSM `!pulse_active`（脉冲期间恒冻结），不依赖斜率，风险低 |
| 2 | 亚阈值脉冲边沿污染基线 | 基线轻微偏高 | 斜率二级门控 `slope_th` 拦截；需实验标定阈值 |
| 3 | 高事件率下非脉冲间隙极短 | 基线更新机会少 | 漂移是慢过程，间隙足够；必要时增大 K |
| 4 | 增益/门控参数被 PS 改写 | 基线突变，相对检测误锁 | `acquire_force` + 看门狗退回 ACQUIRE |
| 5 | 负极性通道 | 减法方向与检测方向错误 | **已确认无负向通道（第 10 节决议 1），此风险不适用** |
| 6 | 定点截断粘滞 | 基线更新停摆 | 6 位小数位；移位用算术 `>>>` 保持有符号 |
| 7 | 滤波延迟与基线错位 | peak/area 与基线不对齐 | 统一使用 `ad_data_array`（滤波后）作为唯一数据源 |
| 8 | 看门狗阈值不当 | 长脉冲被误判卡死 | `MAX_PULSE_WID` 须大于最大真实脉宽，留裕量 |
| 9 | `event_done` 误清基线 | 漂移追踪中断 | 基线状态独立于事件边界，明确不复位 |
| 10 | 寄存器表多处同步 | 改寄存器不同步导致错位 | 沿用「改一处同步所有引用」纪律，更新 `code_review.md` |

## 8. 调试与测试方案

### 8.1 仿真测试（RTL testbench）

**测试向量构造**：基线 + 脉冲 + 噪声叠加，覆盖：

- 基线形态：常数 / 线性慢漂移 / 阶跃（模拟增益跳变）；
- 脉冲：窄脉冲（<20 拍）、宽平顶脉冲（>100 拍）、不同幅度；
- 极性：仅正脉冲（已确认无负向通道，见第 10 节决议 1）；
- 噪声：高斯白噪声（量化到 ADC LSB 级）。

**验证点**：

1. ACQUIRE 阶段：基线快速收敛，`baseline_valid` 在 N 拍内按时置位；
2. TRACK 阶段：基线跟踪慢漂移，**脉冲期间基线冻结**（对比 `pulse_active` 波形）；
3. 校正精度：`peak_corrected`/`area_corrected` 与「真值（已知基线+已知脉冲参数）」误差在容差内；
4. 相对阈值：基线阶跃后仍能正确触发，无漏触/误触；
5. 看门狗：构造 `pulse_active` 长高场景，验证自动退回 ACQUIRE；
6. 面积等价性：逐样本减 vs 度量级减两种实现结果一致。

### 8.2 上板测试（ILA）

- 抓 `baseline`、`baseline_valid`、`pulse_active`、`sample_in`、`sample_baselined`；
- 场景：无样本（纯基线）、正常样本流、运行中切换增益；
- 观察：基线收敛曲线、脉冲期间冻结、漂移跟踪、重收敛行为。

### 8.3 PS 联调

- 通过 AXI 回读 `baseline_mon` / `baseline_valid_mon` 验证硬件状态；
- 上位机下发参数（K、N、slope_th 等）验证通路与默认值；
- `acquire_force` 触发后验证 `baseline_valid` 翻转与重收敛。

### 8.4 量化验收指标

| 指标 | 目标 |
|---|---|
| 峰值校正误差 | 施加已知基线漂移后，`peak_corrected` 误差 < ±1%（满幅） |
| 面积校正误差 | 同漂移下，`area_corrected` 误差 < ±2% |
| 漂移抑制 | 基线阶跃前后 peak/area 结果漂移量 < 阈值 |
| 触发正确性 | 基线漂移全程无误触/漏触 |
| 资源增量 | 8 通道合计加法器/移位器为个位数级，DSP 增量 0 |
| 时序 | 不引入新的时序违例路径 |

## 9. 与既有设计的关系

- 本方案沿用 `pulse_analyzer` 现有的上升/下降沿去抖（`C_DEBOUNCE_LEN=3`），作为 `pulse_active` 的门控基础；
- 与 `code_review.md` 记录的问题协同：
  - 问题 2.2（`ad_data_filter` 2 拍延迟）：基线与峰/面积统一使用滤波后数据即对齐，本方案不引入新错位；
  - 问题 7.2（无脉冲通道残留旧值）：基线不参与事件级清零，独立于该机制；
- `peak_time` 时序不变：减法不移动峰值时刻，分选驱动延时（`drive_signal_generation`）不受影响。
