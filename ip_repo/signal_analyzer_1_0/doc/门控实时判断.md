## 门控实时判断

在FPGA中，通过定义的门控信息和目标数据点实时判断一个数据点是否位于门控范围内，要求判断时间控制在20个时钟周期以内。门控实时判断的模块接口大致如下：

```verilog
module gate_judge # (
	parameter C_NUM_MAX_POINTS = 12,		// max points num in a gate
    parameter C_POINT_DATA_WIDTH = 32		// point data width
)(    
	input wire  rst_n,						// reset
    input wire  sys_clk,					// clk
    input wire  enable,						// enable
    input wire  trigger,						// rising edge: trigger a gate judgement
    input wire [C_POINT_DATA_WIDTH-1:0] point_x,
    input wire [C_POINT_DATA_WIDTH-1:0] point_y,
    input wire [2:0]					gate_type,			// gate type: 1: interval gate, 2: rectangle gate, 3. polygon gate, 4. ecllipse gate 
    input wire [$clog2(C_NUM_POLYGON_POINTS)-1:0] gate_points_num,	// gate points number
    input wire [C_POINT_DATA_WIDTH * C_NUM_POLYGON_POINTS-1:0] gate_points_x_pack,	// gate points x value in flat
    input wire [C_POINT_DATA_WIDTH * C_NUM_POLYGON_POINTS-1:0] gate_points_y_pack, // gate points y value in flat
    output wire valid,						// high: the output result is updated and valid
    output wire result						// judge result
);
    
```

### 门控判断说明：

| 门控类型       | 传入的模块的门控points数据                                   | 判断方法                                                    |
| -------------- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| Interval Gate  | gate_type: 1, gate points_num: 2,  此时point_y和gate_points_y_pack都是无效的，不参与判断 | 直接判断传入的point_x是否在gate的x_min和x_max之间           |
| Rectangle Gate | gate_type: 2, gate points_num: 2，此时两个points分别是矩形的左下角和右上角顶点坐标（保证矩形边平行于坐标轴） | 判断是否满足：x_min <point_x<x_max && y_min < point_y<y_max |
| Polygon Gate   | gate_type:3， gate_points_num: [3, 12], 此时points代表多边形顶点的坐标，最少3个，最多12个 | 通过射线法判断穿过多边形的边的次数和来判断是否在多边形内部  |
| Ellipse Gate   | gate_type:4, gate_points_num: 2, 此时points代表椭圆的外切矩形的左下角和右上角顶点坐标。（保证矩形边平行于坐标轴） | 通过顶点坐标得到椭圆表达式，带入测试点，判断是否在椭圆内    |
| Quadrant Gate  | 在传入底层FPGA时也是按照矩形门控传递的，一个QuadrantGate 会生成四个矩形门控，最终会选择其中一个象限（矩形）传递到实时判断模块中，只不过矩形的其中一个顶点是数据范围的极限值。 | 与矩形门控相同                                              |



  多边形流水线架构                                                                                                                
                                                                                                                                  
  Cycle 1:  S1(edge 0)                          ← 计算差值，寄存                                                                  
  Cycle 2:  S2(edge 0)  +  S1(edge 1)           ← 乘法+累积 | 下一条边差值                                                        
  Cycle 3:  S2(edge 1)  +  S1(edge 2)                                                                                             
    ...                                                                                                                           
  Cycle N:  S2(edge N-2) + S1(edge N-1)                                                                                           
  Cycle N+1: S2(edge N-1)                        ← 最后一次乘法                                                                   
  Cycle N+2: 输出结果
                                                                                                                                  
  - Stage 1（组合逻辑→寄存）：通过 mux 读取当前边的两个顶点，计算 py-y1, x2-x1, px-x1, y2-y1 等差值及 skip 标志，写入 s1_* 寄存器 
  - Stage 2（从寄存器输入的乘法）：lhs = s1_a × s1_b，rhs = s1_c × s1_d，比较后 XOR 到 crossing_acc 累积器                        
                                                                                                                                  

  资源对比                                                                                                                        
                                                                                                                                  
  ┌──────────────┬─────────────────────┬────────────────────────────────┐                                                         
  │              │ 并行版 (gate_judge) │ 流水线版 (gate_judge_pipeline) │
  ├──────────────┼─────────────────────┼────────────────────────────────┤                                                         
  │ 32×32 乘法器 │ 2 × 12 = 24 个      │ 2 个（时分复用）               │
  ├──────────────┼─────────────────────┼────────────────────────────────┤
  │ DSP48E2 估算 │ ~48-72              │ ~4-6                           │                                                         
  ├──────────────┼─────────────────────┼────────────────────────────────┤                                                         
  │ 多边形延迟   │ 2 cycles            │ N+2 cycles (max 14)            │                                                         
  └──────────────┴─────────────────────┴────────────────────────────────┘                                                         
                  
  乘法器的输入来自寄存器（s1_a/b/c/d），可以被 Vivado 直接映射到 DSP48 的 A_REG/B_REG 输入寄存器，时序表现良好。
