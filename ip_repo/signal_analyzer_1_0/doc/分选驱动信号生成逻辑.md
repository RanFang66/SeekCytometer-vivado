## 分选驱动信号生成逻辑



1. 当一个事件通过时（一个细胞通过检测位置），event aggregator会完成所有使能通道的信号的分析，更新最新的分选结果，并给出一个事件通过的信号，开始启动分选判断。
2. 在一个事件结束后，判断设定的分选门控对应的两个分选通道在刚结束的事件中是否满足分选门控条件（有有效脉冲，且对应的通道参数在分选门控内），如果不满足则直接放弃本次事件不分选，如果满足则进行第2步判断。
3. 判断是否开启高纯度模式，如果没开启则直接给出分选驱动开始信号。如果开启高纯度模式，则判断上次事件是否分选，如果上次事件不满足分选门控条件，并且本次事件和上次事件的事件间隔小于设定的最小事件间隔，则放弃本次分选。如果上次事件也满足分选条件或者相隔时间大于设定的最小事件间隔时间，则给出分选启动信号。
4. 驱动控制模块在收到分选开始信号后，如果处于IDLE状态，则开始本次分选驱动信号生成，进入wait状态，并更新本次分选驱动延时（根据速度计算出的延时+直接设定的分选延时），得到驱动开始的时间。如果不处于IDLE状态（上次分选未结束），则放弃本次分选。
5. 驱动信号状态机在wait状态时，如果使能了高纯度模式，并且新来了一个不满足分选门控条件的事件，并且这个事件与当前等待分选事件的时间差小于设定最小事件间隔时间，则放弃本次分选，回到IDLE状态，否则都继续本次分选。
6. 驱动信号状态机在wait状态时，如果当前时间达到分选开始时间，则输出分选驱动信号（edge模式直接翻转电平直到下一次分选事件，level模式则输出设定的drive_width(us)长度的高电平）。并且更新冷却时间，进入冷却状态（cooling_down）。
7. 当当前时间超过了冷却时间，则驱动控制状态回到IDLE状态，可以接受下一次分选驱动信号的生成。
